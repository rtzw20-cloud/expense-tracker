# 离线记账

纯前端的离线记账 PWA:原生 HTML/CSS/JS,无构建步骤,无外部网络请求、CDN、统计或密钥。货币单位为 RM。

本应用只读取和记录数据,不会动用任何资金。

## 运行

Service Worker 和 WebCrypto 需要安全上下文,因此必须通过 `localhost` 或 HTTPS 打开,`file://` 无法运行。

```sh
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

**在 iPhone 上使用:** 把本目录部署到任意 HTTPS 静态托管(其中不含任何个人数据),用 Safari 打开,再选择“添加到主屏幕”。首次打开后即可完全离线使用。务必从主屏幕图标使用:Safari 可能清除长期未访问网站的数据,主屏幕应用不受此限制。

数据只保存在该设备、该网址对应的浏览器存储中。更换设备、更换托管网址或卸载主屏幕应用都会丢失数据,请定期导出 CSV 备份。

## 设置 iOS 快捷指令

应用无法自行读取“文件”App,需由快捷指令写入 CSV,再由你手动选择该文件同步。

1. 在“快捷指令”App 中新建自动化,例如“钱包”交易触发(iOS 17 及以上),或自行手动运行的快捷指令。各系统版本的操作名称可能略有差异。
2. 添加“格式化日期”操作,自定义格式为 `yyyy-MM-dd HH:mm`。
3. 添加“文本”操作,内容为:`日期,金额,商户,卡片`。
4. 添加“附加到文件”操作,文件为 `记账/expenses.csv`,并**开启“新行”选项**。否则新记录会接在上一行末尾,导致解析失败。

每行格式如下:

```
2026-03-15 12:30,RM 1,234.50,Foo, Inc,Maybank Visa
2026-03-15 18:05,12.50,"Bar, ""Best"" Cafe",信用卡
```

- **金额**可包含 `RM`、`MYR`、千分位逗号和空格,必须大于 0,最多两位小数。退款等负数金额会被计入“失败”。
- **商户**为金额之后、最后一个字段之前的全部内容,可含逗号,也可加引号。
- **卡片**为最后一个字段。

未加引号的金额中,逗号后跟三位数字时视为千分位:`12,345,Shop,Visa` 解析为 RM 12,345.00,商户 `Shop`。若商户名恰好以独立的三位数字开头,请给金额或商户加引号。

## 同步与去重

点击“同步快捷指令记录”并选择 CSV 文件,应用会显示新增、跳过和失败的条数,并可查看失败的行。

每行的去重键为“原始行内容 + 该行在文件中第几次出现”的 SHA-256:

- 反复选择同一个不断增长的文件是幂等的,只会导入新增的行。
- 内容完全相同的两行(如同一分钟买了两杯咖啡)会被视为两笔记录。
- 已删除或已编辑的导入记录不会在下次同步时恢复。
- 失败的行不会被记录,修正 CSV 后可重新导入。

请只在文件末尾追加内容。若修改了已导入的行,它会被视为新记录;若删除了相同行中的一行,之后再追加相同内容时可能被跳过。

## 安全设计

- 记录和去重键均以 AES-GCM(256 位)加密后保存在 IndexedDB,每次加密使用随机 IV,记录 ID 作为附加认证数据。
- 密钥由密码经 PBKDF2-SHA256(600,000 次迭代、16 字节随机盐)派生,不可导出,且只保存在内存中;锁定后即丢弃。
- 通过解密校验值判断密码是否正确,不保存密码或其哈希。
- 内容安全策略(CSP)禁止页面连接任何外部地址,所有用户数据均以文本方式写入页面。

**局限:**

- 忘记密码后数据无法恢复。
- 他人取得设备存储后可离线尝试猜测密码,因此密码越长越安全,纯数字短密码防护有限。
- 记录条数、每条记录的大致长度和盐值未加密。
- 加密无法防御已解锁时的设备访问,离开时请点击“锁定”。应用不会自动锁定。
- 导出的 CSV 是明文。
- 应用代码来自托管网址,请使用你信任的托管服务。

## 开发

```sh
npm test                 # 或 node test/test.mjs,测试解析、去重和加密逻辑
python3 gen_icons.py     # 重新生成图标
```

修改任何资源文件后,必须更新 `sw.js` 中的 `VERSION`,否则已安装的应用会继续使用旧缓存。新增资源文件时,还要加入同一文件的 `ASSETS`。
